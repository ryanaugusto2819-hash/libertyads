# LibertyAds

Crie um dashboard profissional para relatorio de anuncios e metricas faceboook ads,  ele tera todas as informações de valor gasto, quantidade de leads recebidos, custo por lead, cUSTO POR VENDa, Faturamento total, Quantidade de vendas, ROI, E tambem tera abas que sera as seguintes metricas por anuncios, CPM, CT, Hook rate, Body rate, CPL, CPA, Cada anuncio tem um nome, e as informações sera filtradas por datas persoanlizadas, Hje, Ulimos 7 dias, ultimos 30 dias. quero um dashboard com visual boito.
